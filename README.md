# Personal academic homepage

This is an English-only static website. No build tools or dependencies are required.

## 修改内容

编辑 assets/profile.js；字段说明见 FILL-IN.md。照片放 assets/images/，简历放 assets/files/。双击根目录 index.html 可预览。

## 发布 GitHub Pages

1. 创建公开仓库：你的用户名.github.io。
2. 上传本文件夹内的内容，确保 index.html 位于仓库根目录，不要只上传 ZIP。
3. 确认根目录有隐藏空文件 .nojekyll。
4. Settings → Pages → Deploy from a branch → main → /(root) → Save。
5. 发布后访问 https://你的用户名.github.io/。

若替换之前的双语版本，请删除 GitHub 仓库中的旧 en 文件夹，上传新的 index.html 和 assets 文件。当前版本只有英文主页，没有语言切换。
